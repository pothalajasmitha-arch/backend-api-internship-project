# Submission Description

This submission documents and implements the five-week backend API assignment as a single GitHub project. The work preserves an important scope change in the supplied instructions: Week 1 asks for the design of an e-commerce API, while Weeks 2–5 ask for development and testing of a blog API. Rather than mixing the domains, the repository contains an OpenAPI 3.1 contract and requirements/design report for the e-commerce system, plus a separate SQLite-backed blog API for the implementation weeks.

The Week 1 materials identify functional and non-functional requirements for customers, products, inventory, and orders. They define methods, paths, request and response schemas, authentication boundaries, validation rules, error codes, and security controls. Mermaid diagrams show resource relationships and the order-checkout sequence. The machine-readable OpenAPI file can be rendered with Swagger Editor or another OpenAPI-compatible tool.

For the blog implementation, the project includes account registration and login, salted password hashing, signed bearer tokens, post CRUD, comment CRUD, database constraints, input validation, ownership authorization, and consistent JSON error responses. Automated integration tests exercise the main workflows and security boundaries against an isolated SQLite database. A GitHub Actions workflow runs the test suite on pushes and pull requests, providing the requested continuous integration simulation without requiring secrets or production infrastructure.

The performance-testing materials provide a repeatable concurrent request script and a method for comparing latency percentiles, throughput, and errors before and after a measured optimization. No performance figures are invented: actual results must be generated on the machine and dataset where the benchmark is run. The project README explains prerequisites, installation, startup, testing, and repository contents. This submission therefore includes a design specification, implementation, tests, CI configuration, diagrams, and a roadmap for production hardening.
